# Rutwater

An offroad driving game that runs in the browser (three.js).

- 4 maps: Rutwater Valley, Thar Desert, Himalayan Pass, Navapur City
- 8 vehicles, raycast suspension, soft-body style crash damage, winch, low range
- Expedition mode (find landmarks) and timed trail runs
- Keyboard, gamepad and touch controls

Play: https://harshdeepsingh888-ps.github.io/rutwater/

Controls: W/S gas and brake, A/D steer, L low range, Space handbrake, E winch, R recover, N map, C camera, Esc pause.
